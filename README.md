# Jiajun Wu's homepage

Personal academic homepage for `Sunshine-oneday.github.io`.

The page uses the Jekyll layout and publication component from [Jiahao Zhang's public homepage](https://github.com/JiahaoZhang-Public/JiahaoZhang-Public.github.io), adapted with Jiajun Wu's content. The theme is distributed under the MIT license in [LICENSE](LICENSE).

The text-only Projects list follows the Markdown structure of [Qiguang Chen's homepage source](https://github.com/LightChen233/LightChen233.github.io).

To preview locally:

```sh
bundle install
RUBYOPT=-r./scripts/jekyll-ruby-compat.rb bundle exec jekyll serve --host 127.0.0.1 --port 4000
```
